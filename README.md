# Calculadora Vue

Exercício do módulo 27 (EBAC): calculadora aritmética feita com Vue 3.

- Dois campos numéricos e um select com a operação (+, -, ×, ÷)
- O resultado é recalculado automaticamente (`computed`) sempre que um valor muda, sem botão
- Trata divisão por zero

## Como rodar

```bash
npm install
npm run dev
```
